# Designing the AI experience: what's old, what's new?

Slide deck for Kalina Tyrkiel-Szymańska’s CAKE conf 2026 talk.

Built from the WaysConf Roundtable foundation, restyled to match [CAKE conf](https://cakeconf.contentbytes.pl/) visuals.

## Run locally

```bash
npm install
npm run dev
```

Navigate with arrow keys, space, or click. Use `←` / `→` buttons in the footer.
